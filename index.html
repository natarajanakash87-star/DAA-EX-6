Optimal Cost Computation in Matrix Chain Multiplication

Dynamic Programming Technique

Problem Statement

Given a chain of four matrices with the following dimensions:

  • A1 = 10 × 30
  • A2 = 30 × 5
  • A3 = 5 × 60
  • A4 = 60 × 10

Find the optimal order of multiplication using Dynamic Programming and determine the minimum number of scalar multiplications.

Objectives

  • Implement Matrix Chain Multiplication using DP.
  • Calculate the minimum multiplication cost.
  • Find the optimal parenthesization.
  • Construct the DP cost table.
  • Analyze the time and space complexity.

Dynamic Programming Formula


m[i][j] = min {
    m[i][k] + m[k+1][j]
    + p[i-1] × p[k] × p[j]
}

where:

i ≤ k < j

Matrix Dimensions

Matrix Rows Columns
A1 10 30
A2 30 5
A3 5 60
A4 60 10

Optimal Multiplication Order

((A1 × A2) × (A3 × A4))

Minimum scalar multiplications: 5000

Cost Calculation


Step 1:

A1 × A2

= 10 × 30 × 5
= 1500


Step 2:

A3 × A4

= 5 × 60 × 10
= 3000


Step 3:

(A1A2) × (A3A4)

= 10 × 5 × 10
= 500


Total Cost:

1500 + 3000 + 500

= 5000 scalar multiplications

Dynamic Programming Approach

The DP table stores the minimum number of scalar multiplications required to multiply matrices from Ai to Aj. For every possible split point k, the algorithm calculates the cost and selects the minimum value.
